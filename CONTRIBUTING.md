# Contributing

Thanks for your interest in contributing.

## Getting started

1. Fork the repository and create a feature branch from `master`.
2. Set up your environment using `RUN_INSTRUCTIONS.md`.
3. Keep changes focused and small where possible.

## Development guidelines

- Follow the existing project structure (`dags/`, `producers/`, `streaming/`, `requirements/`).
- Do not commit local-only paths, credentials, or `.env` files.
- Keep documentation up to date when behavior or commands change.

## Pull requests

Please include:

- A short summary of what changed and why
- Any relevant run/validation notes
- Updated docs when applicable

## Reporting issues

When opening an issue, include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs/screenshots when helpful
